# @adrift/shared

Reserved for future shared JavaScript utilities, constants, or schema helpers.

Do not place React UI, Express routes, or Swift files here. Product-specific code should stay in:

- `apps/web`
- `apps/api`

Native Swift code belongs in the independent
[Adrift-iOS](https://github.com/EnJu1018/Adrift-iOS) repository. It consumes the
HTTP API, not local JavaScript packages from this repository.
